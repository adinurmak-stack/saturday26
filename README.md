# Бот-помощник — СРС №2

## Описание добавленных модулей

**Модуль 1 — Учет рабочего времени**
Запрашивает количество рабочих дней в неделе и ставку, рассчитывает норму часов
в день. Если введённое количество часов меньше нормы — выводит предупреждение
с расчётом дефицита в часах и процентах. Программа блокирует дальнейшую работу
до тех пор, пока пользователь не введёт и не подтвердит норму часов в день.

**Модуль 2 — Дисциплинарные взыскания**
Оформляет инцидент с самовольным выносом учебного ноутбука за пределы кабинета
и выводит структурированный перечень применимых положений устава ВУЗа.

**Модуль 3 — Протокол реагирования на саботаж**
Последовательно, с паузами между шагами (`std::this_thread::sleep_for`),
выводит все этапы протокола: фиксация нарушения, уведомление руководства,
проверка доказательной базы, подача служебной записки, административные
последствия.

Старое меню и контрольные вопросы сохранены и работают как прежде.

## Компиляция и запуск

```
g++ main.cpp -o bot -pthread
./bot
```

Компилируется без предупреждений (`-Wall -Wextra`), корректно обрабатывает
некорректный ввод (буквы вместо чисел и т.п.).

## Структура репозитория

- `main.cpp` — итоговый рабочий код со всеми модулями
- `stages/` — промежуточные версии файла, соответствующие каждому коммиту
  (для наглядности, как код рос модуль за модулем)
